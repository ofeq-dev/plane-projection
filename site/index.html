Plane projections of 3D voxel volumes, from NRRD to MP4

One NRRD volume, one CSV plane-list, one MP4 — a frame per plane. Voxels are sampled with a closest-voxel rule, invalid planes fail loudly with an error frame in the video, and a 500³ uint8 volume renders well above the 30 FPS hard bar.

What it does

Everything from the exercise brief, with the engineering around it: typed seams, golden tests, and a reproducible benchmark harness.

INPUT

NRRD volume loader

Reads 8-, 16- and 32-bit unsigned volumes up to 1024³ per axis (v = M[x][y][z]), with the geometry cached for fast repeat runs.

VALIDATE

Plane validation

3-point planes must be equidistant from a common origin; 4-point planes must form a proper rectangle. Invalid specs raise and produce a visible error frame.

RENDER

Closest-voxel sampling

Each output pixel takes the nearest voxel centre on the plane — deliberately simple, axis-wise fast-path geometry keeps it quick.

ENCODE

MP4 via OpenCV

cv2.VideoWriter with the mp4v codec — pip-installable, no system ffmpeg needed (ADR 0004), canonical 30 fps.

VERIFY

Tested & typed

pytest suite with golden-frame oracles, CLI and validation tests, plus mypy --strict on the whole package.

MEASURE

Benchmark harness

bench.py measures load and render scopes separately, min-of-repeats, with a dedicated encode probe and versioned results files.

Pipeline

One command, one video. Every stage is a seam that is tested in isolation.

INPUT volume.nrrd

3D unsigned voxel array, 8/16/32-bit

INPUT planes.csv

3 or 4 points per plane; validated on load

RENDER project()

Closest-voxel sampling → one 2D frame per plane

OUTPUT out.mp4

One frame per plane; error frames for invalid planes

Quickstart

Python ≥ 3.10 (exercised on 3.12). Everything is pip-installable.

# clone + set up
$ git clone https://github.com/ofeq-dev/plane-projection.git
$ cd plane-projection
$ python -m venv .venv && . .venv/bin/activate
$ pip install -r requirements.txt

# render a video: volume + plane list → mp4
$ python Ex0.py assets/nrrd/MRHead_1.nrrd assets/csv/lecturer_example.csv out.mp4

# tests, typecheck, benchmark
$ python -m pytest
$ python bench.py assets/nrrd/croissant.nrrd assets/csv/croissant.csv --repeats 3
